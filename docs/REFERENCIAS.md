# Referencias técnicas

Se utilizan para el contrato de integración y el diseño de las pruebas. No implican certificación del proyecto ni que todas las medidas descritas en ellas estén implementadas.

- [Ollama: llamadas de herramientas](https://docs.ollama.com/capabilities/tool-calling). Formato de propuestas y respuestas de herramientas.
- [Ollama: Chat API](https://docs.ollama.com/api/chat). Solicitudes no streaming y parámetros de generación.
- [Ollama: modelos locales](https://docs.ollama.com/api/tags). Listado e identificación del modelo.
- [Ollama: configuración](https://docs.ollama.com/faq). Variables del servidor y funciones cloud.
- [OWASP: prevención de prompt injection](https://cheatsheetseries.owasp.org/cheatsheets/LLM_Prompt_Injection_Prevention_Cheat_Sheet.html). Fronteras de confianza, permisos y observación de efectos.
- [MITRE ATLAS: publicaciones del catálogo](https://github.com/mitre-atlas/atlas-data/releases). Referencia para futuros mapeos versionados; no se afirma cobertura completa del catálogo.
- [actions/checkout](https://github.com/actions/checkout) y [actions/setup-python](https://github.com/actions/setup-python). Acciones oficiales utilizadas por el workflow configurado.

Los resultados propios se respaldan con los archivos de [`evidence/`](../evidence/README.md), no con estas referencias.
